# Nigeria state boundaries

Source: GRID3, distributed by geoBoundaries (gbOpen NGA ADM1, boundary year 2022).

https://www.geoboundaries.org/api/current/gbOpen/NGA/ADM1/

Original dataset: https://data.grid3.org/datasets/grid3-nigeria-state-boundaries/explore

License: Creative Commons Attribution 4.0 International — https://creativecommons.org/licenses/by/4.0/

The simplified GeoJSON from geoBoundaries release 9469f09 was converted to SVG path coordinates, rounded to half-pixel precision, and assigned portal state codes. These generalized boundaries are for dashboard visualization, not surveying.
